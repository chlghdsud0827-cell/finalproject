## 6단계에서 발견해 수정한 버그 (참고)
1. **정원 초과 버그**: 관리자가 대기중 지원자를 "합격"으로 수동 변경할 때 정원 체크가 없어 정원을 초과할 수 있었음 → `ApplicationContext.jsx` 가드 추가로 수정
2. **모바일 헤더 반응형 깨짐**: 375px 폭에서 내비게이션이 글자 단위로 줄바꿈되어 전체 페이지 상단이 깨짐 → `Header.css`에 640px 브레이크포인트 추가로 수정

## 8단계에서 발견해 수정한 버그 (참고)
- **로그인 세션-데이터 조회 레이스 컨디션**: `Application`/`Consultation`/`Callback`/`Inquiry`/`Community` 5개 Context가 앱이 처음 켜질 때 딱 한 번만 Supabase에서 데이터를 조회하고 있었음. Supabase 세션 복원은 비동기라, 이 최초 조회가 세션 복원 전에 먼저 실행되면 RLS(`select to authenticated`)가 막아 빈 배열을 반환하는데, 이후 로그인이 끝나도 재조회 트리거가 없어 빈 상태가 그대로 굳어버리는 문제였음(관리자가 로그인해도 문의 목록이 안 보이는 등) → 각 Context의 조회 `useEffect` 의존성 배열에 `currentUser`를 추가해 로그인 상태 변화 시 재조회되도록 수정.

## 비회원 콜백 신청 폼 연결 — 완료 (2026-08-12)
`docs/사용자시나리오.md` 작성 중 관리자/멘토 화면의 "비회원 상담 관리"는 이미 만들어져 있는데 정작 신청을 접수하는 화면이 없어 채워질 일이 없다는 걸 발견 → 플로팅 버튼 "전화 상담" 모달에 "지금 통화하기 어려우신가요? 번호를 남겨주시면 저희가 먼저 연락드립니다" 콜백 신청 폼을 추가해 연결. 비회원으로 신청 → 관리자 "상담 관리" 탭(비회원 신청 관리)에 노출 → 담당 멘토 지정/연락완료 표시까지 Playwright로 검증 완료.
