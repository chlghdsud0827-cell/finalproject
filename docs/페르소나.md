# 페르소나

기획 초반에 이 사이트를 누가, 왜 쓰게 될지 그려보려고 만든 인물들이다. 실제 화면 설계(어떤 메뉴를 우선 보여줄지, 로그인 없이도 할 수 있는 걸 어디까지 열어둘지, 관리자가 뭘 관리해야 하는지)를 정할 때 이 네 명을 기준으로 판단했다. 지원자・멘토・관리자 세 명은 기획 초기에 정한 대표 페르소나이고, 예비 지원자(비회원)는 문의・콜백 기능을 만들면서 필요해져 추가했다.

## 김민지 (27세) — 지원자

비전공자로 일하다가 UI/UX 디자이너로 커리어를 바꿔보려는 사람이다. 관련 학과를 나오지 않아서 "나 같은 사람도 할 수 있을까"라는 불안이 크고, 국비지원 조건을 만족하는지도 헷갈려한다. 검색해서 들어온 학원 홈페이지에서 커리큘럼과 수료생 사례부터 확인하고, 바로 지원하기보다는 상담을 먼저 받아보고 싶어 한다. 비용 부담이 크기 때문에 국비지원 자격이나 자부담금처럼 구체적인 숫자를 궁금해한다.

이 사이트에서는 홈 화면과 과정 소개 페이지에서 커리큘럼・수료생 포트폴리오를 확인하고, 회원가입 후 상담을 신청해 멘토를 배정받는다. 배정된 멘토와 이야기를 나눈 뒤 실제 지원서를 제출하고, 마이페이지에서 지원 상태(심사중 → 합격/대기)를 확인한다. 궁금한 게 더 생기면 문의 게시판이나 커뮤니티에 글을 남기기도 한다.

## 지수 — 멘토 (시니어 UX 멘토)

前 라인 UX 디자이너 출신으로, 실무 경험을 살려 포트폴리오 피드백과 Figma 같은 실무 툴 관련 상담을 주로 맡는다. 여러 사람을 동시에 담당하기 때문에 지금 몇 명을 진행 중인지, 누가 배정을 기다리고 있는지 빠르게 파악하는 게 중요하다. 결과물 자체보다 그 과정의 논리를 먼저 보는 스타일이라, 상담 내용을 미리 읽어보고 준비해서 만나는 걸 선호한다.

이 사이트에서는 로그인 후 멘토 대시보드에서 자신에게 배정된 상담 목록과 현재 진행 부하(N/최대)를 확인한다. 새로 배정된 상담을 수락하거나, 맡기 어려운 건은 거절해 관리자가 다시 배정하도록 넘긴다. 상담을 마치면 완료 처리하고, 잘못 눌렀을 때는 상태를 직접 되돌릴 수도 있다.

## 성훈(김성훈) — 관리자

학원 운영을 총괄하는 대표다. 정원 관리, 상담 배정, 문의 응대, 일정 공지처럼 학원이 돌아가는 데 필요한 실무를 직접 처리한다. 지원자가 몰릴 때 정원을 넘기지 않으면서도 대기자를 놓치지 않는 것, 상담 신청이 쌓였을 때 알맞은 멘토에게 빠르게 배정하는 것이 주요 관심사다. 관리 화면이 복잡하면 실수로 잘못된 처리를 할 수 있어서, 지금 무엇이 몇 건 밀려있는지 한눈에 보이는 걸 중요하게 생각한다.

이 사이트에서는 관리자 대시보드에서 지원자 상태를 개별/일괄로 변경하고, 정원이 찬 과정은 합격 처리 자체가 막히도록 설계된 화면을 쓴다. 상담 매칭 모니터링에서 신청자와 멘토의 분야・부하를 보고 수동으로 배정하며, 문의 게시판에 올라온 질문에 답변을 등록하고, 학원 일정(모집・수업・행사)을 추가・수정한다.

## 예비 지원자 (비회원)

아직 회원가입까지는 마음을 못 정한 사람이다. 광고나 검색을 통해 우연히 들어왔고, 국비지원이 정확히 뭔지, 이 학원이 믿을 만한지부터 알아보는 단계다. 회원가입은 진입장벽으로 느껴져서, 가입 없이도 궁금한 걸 물어볼 수 있는 방법이 있으면 훨씬 편하게 느낀다.

이 사이트에서는 로그인 없이 국비지원 안내・FAQ・커뮤니티・공지사항을 둘러볼 수 있고, 마음에 걸리는 게 있으면 문의 게시판에 비회원으로 이름・연락처와 함께 질문을 남기거나, 화면 우측 하단 플로팅 버튼으로 담당 분야 전화번호에 바로 연결한다. 문의 답변을 받아보고 신뢰가 생기면 그때 회원가입으로 넘어가 김민지와 같은 흐름을 타게 된다.
