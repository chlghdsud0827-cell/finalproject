# 기능 테스트 결함 발견 및 수정 보고서

2026-07-31 ~ 2026-08-12 동안 개발과 병행해 기능 테스트를 진행했다. 발견한 주요 결함과 조치 내용은 아래와 같다.

## 핵심 기능

- **정원 초과** — 관리자가 대기자를 합격 처리할 때 정원 체크가 없어 정원을 넘겨 확정될 수 있었음 → 상태 변경 시마다 정원을 재검증하도록 수정, 정원이 찬 과정은 합격 옵션 자체를 비활성화.
- **마이페이지 배지 오류** — 이미 합격한 회원도 배지가 계속 "지원자"로만 표시됨 → 실제 지원 상태를 기준으로 배지를 계산하도록 수정.
- **비회원 상담 배정 건수 미반영** — 멘토에게 비회원 상담을 배정해도 진행 건수가 안 바뀜 → 정규 상담과 비회원 상담을 합산하도록 수정.

## 화면/레이아웃

- **모바일 헤더 붕괴** — 좁은 화면에서 메뉴 글자가 한 글자씩 줄바꿈돼 상단 전체가 깨짐 → 반응형 브레이크포인트 추가.
- **여정 그래프 좌표 밀림・애니메이션 오류** — 모바일에서 진행 단계가 화면 밖으로 밀려나거나 애니메이션이 끊기는 문제 → 실제 DOM 좌표를 측정해 그리는 방식으로 재설계.
- **헤더 드롭다운 호버 오류** — 마우스를 서브메뉴로 옮기면 메뉴가 먼저 닫히거나, 터치 기기에서 탭해도 안 열림 → CSS 여백 구조와 터치/마우스 분기 처리 수정.
- **/schedule 캘린더 정렬 어긋남** — 요일 헤더와 날짜 칸이 밀림 → 그리드 트랙 폭 고정.
- **히어로 영상 잘림・어두움** — 영상이 과도하게 확대되거나 오버레이가 전체를 덮음 → object-fit・그라디언트 방향 수정.
- **관리자 화면에 개발자용 문구 노출** — 파일 경로가 그대로 보임 → 사용자용 문구로 교체.

## 백엔드/데이터

- **Supabase 권한(RLS) 오류** — 신규 스키마에 기본 접근 권한이 없어 모든 DB 작업이 막힘 → 스키마 권한 부여 마이그레이션 추가, 계정 없는 더미 데이터용 예외 정책도 별도 추가.
- **게시판/일정이 저장되지 않음** — 커뮤니티・문의・학원 일정이 Supabase 연동 전이라 새로고침하면 사라지고 다른 사용자에게 안 보임 → 각각 전용 테이블・RLS로 전환.
- **로그인 세션-데이터 조회 레이스 컨디션** — 로그인 직후 여러 화면(관리자 대시보드 등)에서 데이터가 빈 것처럼 보이는 문제. 지원・상담・콜백・문의・커뮤니티 5개 영역이 앱 최초 실행 시 딱 한 번만 데이터를 조회하고, 로그인 세션 복원이 그보다 늦으면 빈 결과가 고정되는 구조적 원인 → 로그인 상태가 바뀔 때마다 재조회하도록 수정.
- **계정 연결 끊김** — 계정을 Supabase Auth로 옮기면서 특정 테스트 계정의 합격・상담 이력 연결이 끊김 → 새로 발급된 계정 id로 데이터 재연결.
- **지도 좌표 오류** — 지점 지도가 학원이 아니라 인근 지하철역・주차장・도로 위치를 가리킴 → 지오코딩 서비스로 좌표 재검증.

## 결론

크고 작은 결함 총 29건을 발견해 전부 수정하고 재검증까지 완료했다. 초반에는 정원 초과・반응형 붕괴처럼 핵심 기능에 직접 영향을 주는 결함이 많았고, 백엔드를 Supabase로 옮긴 뒤로는 권한 설정과 데이터 저장 관련 결함의 비중이 커졌다. 현재 알려진 미해결 결함은 없다.
